# A&D Student CTF — тренировочный стенд

Локальный полигон в формате **Attack & Defense**, как на финале Студент CTF: 10 команд,
у каждой одинаковый набор уязвимых сервисов. Центральная **checksystem** каждый тик
раскладывает по сервисам свежие флаги, проверяет работоспособность (SLA) и принимает
украденные флаги. Ты играешь за `team1` (её же защищаешь), а `team2…team10` — противники,
которых атакуешь.

> ⚠️ Сервисы **намеренно уязвимы**. Всё крутится только на `127.0.0.1` и внутри Docker.
> Не выставляй порты в сеть и не запускай это на боевой машине.

## Сервисы (3 класса уязвимостей)

| Сервис   | Что это              | Класс уязвимости                        | Транспорт      |
|----------|----------------------|-----------------------------------------|----------------|
| `web`    | SecureNotes (заметки)| SQL-инъекция                            | HTTP (Flask)   |
| `crypto` | CipherVault (секреты)| повторное использование гаммы AES-CTR   | HTTP (Flask)   |
| `depot`  | Depot (key/value)    | path traversal                          | сырой TCP      |

У каждого сервиса в папке `services/<name>/`:
`README.md` (описание интерфейса, без спойлеров) · `HINTS.md` (подсказки под спойлером) ·
`sploit.py` (рабочий эталонный эксплойт) · `solution.md` (полный разбор + патч) ·
`app.py` (сам уязвимый сервис) · `checker.py` (чекер).

## Быстрый старт (без Docker — работает прямо сейчас)

На этой машине **PyPI и Docker Hub недоступны** (их блокирует сеть/прокси — их видит только
браузер), так что Docker-образы тут не собрать. Зато Flask уже установлен, и весь стенд
поднимается нативно — одной командой, без Docker и без pip:

```bash
./run.ps1 local          # PowerShell   (то же самое:  python run_local.py)
```

Поднимутся 10 боксов (по 3 сервиса) + чекер + скорборд. Открой **http://127.0.0.1:8090** —
через тик-другой сервисы позеленеют (UP). Останов — `Ctrl+C` в этом окне. Атакуй из другого
окна: `./run.ps1 attack --loop`. Логи каждого процесса — в `run/_logs/`.

> 10 команд ≈ 31 python-процесс (~1 ГБ ОЗУ). Если тяжело: `python run_local.py --teams 4`
> (или `TEAMS=4` в [.env](.env)). Длину тика и прочее тоже правь в `.env`.

## Вариант с Docker (когда доступны Docker Hub и PyPI)

Ещё ближе к реальному A&D — каждая команда в отдельном контейнере. Требует рабочего доступа
к реестру Docker и PyPI (сейчас на этой машине они заблокированы, поэтому сборка упадёт):

```bash
./run.ps1 up             # сгенерит compose, соберёт образы и поднимет стенд
```

## Карта портов

| Кому | Что | Адрес |
|------|-----|-------|
| скорборд / сабмиттер | HTTP | `http://127.0.0.1:8090` |
| `teamN` web | HTTP | `127.0.0.1:` + `(9300+N)` |
| `teamN` crypto | HTTP | `127.0.0.1:` + `(9400+N)` |
| `teamN` depot | TCP | `127.0.0.1:` + `(9500+N)` |

Например, `web` третьей команды — `http://127.0.0.1:9303`, её `depot` — `nc 127.0.0.1 9503`.
Порт скорборда правится в [.env](.env) (`SCOREBOARD_PORT`).

## Как тренироваться

**Атака (найти дыру и воровать флаги у team2…team10):**
1. Открой `services/<svc>/README.md` — пойми интерфейс. Поковыряй руками (curl / nc / браузер).
2. Не идёт — `services/<svc>/HINTS.md`, подсказки раскрываются по одной.
3. Укради флаг. Публичные `flag_id` целей лежат на `http://127.0.0.1:8090/api/flag_ids`.
4. Сдай флаг: `POST /flags`, заголовок `X-Team-Token: <твой токен>` (`./run.ps1 token`),
   в теле — по флагу на строку. Либо автоматом — эталонная «ферма»:
   ```bash
   ./run.ps1 attack            # один проход по всем врагам
   ./run.ps1 attack --loop     # крутить каждый тик
   ```
5. Полный разбор и готовый эксплойт — в `sploit.py` и `solution.md`.

**Защита (запатчить сервис, не уронив SLA):**
1. Найди ту же уязвимость и почини `services/<svc>/app.py` (как — в `solution.md`).
2. Проверь патч одной командой (жив ли сервис + закрыта ли дыра):
   ```bash
   python defense/verify.py <svc>      # цель: GOOD PATCH (SLA OK + exploit blocked)
   ```
3. Перезапусти стенд: `Ctrl+C`, затем снова `./run.ps1 local` (в Docker-режиме — `./run.ps1 rebuild`).
   В нативном режиме все боксы запускаются из одного `services/<svc>/app.py`, так что патч
   применяется сразу ко всем — для соло-тренировки это ок. Подробнее про защиту — [defense/README.md](defense/README.md).
   *(со стороны врага; для self-теста см. ARCHITECTURE.md)*.

Это первый коммит-«бейзлайн»: сделай `git commit` после правок, чтобы `git diff` показывал
твои патчи — удобно для разбора защиты.

## Полезное

- `./run.ps1 logs checksystem` — видно, как чекер ходит по командам каждый тик.
- `./run.ps1 ps` — статус контейнеров.
- `./run.ps1 down` — всё погасить (и стереть базу флагов).
- Устройство системы, протокол сабмита, подсчёт очков и запуск **без Docker** —
  в [ARCHITECTURE.md](ARCHITECTURE.md).
