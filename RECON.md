# Разведка по правилам (сверено с `Правила_26.pdf`)

Площадка — **ForcAD** (github.com/pomo-mondreganto/ForcAD), VPN — **WireGuard**.
⚠️ В 2026 сменилась подсеть команд: было `10.80.<team>.2`, стало **`10.60.N.2`**. Раунд — 1 минута,
срок флага — 10 раундов. Основной интерфейс ForcAD виден и из интернета по HTTPS
(адрес `GAME_HOST` объявят перед стартом), внутри VPN — `http://10.10.10.10`.

## Параметры игры (уже зашиты в `farm/config.forcad.py`)

| Что | Значение |
|-----|----------|
| Боксы команд | `10.60.N.2` (N=1..10; первая/последняя — `10.60.1.2`/`10.60.10.2`) |
| Игровой сервер / скорборд | `http://10.10.10.10` (внутри VPN) или `https://GAME_HOST` (из интернета) |
| Раунд | 1 минута (60 с) |
| Срок действия флага | 10 раундов (600 с) |
| Формат флага | `[A-Z0-9]{31}=` |
| Attack-data (flag_id) | `GET http://10.10.10.10/api/client/attack_data` → `{"service":{"team_ip":["hint1","hint2",...]}}` |
| Сдача флагов | `PUT http://10.10.10.10/flags`, заголовок `X-Team-Token: <токен>`, тело — JSON-массив флагов |

Пример сдачи из правил:
```bash
curl -s -H 'X-Team-Token: your_secret_token' -X PUT \
     -d '["PNFP4DKBOV6BTYL9YFGBQ900658 2ADC=","STH5LK9R9OMGXOV4E06YZD71F746F53=", ...]' \
     http://10.10.10.10/flags
```

Ферма под это готова: `python farm/farm.py --config farm/config.forcad.py`. В тест-день заполнить
только: **свой IP** (`10.60.<твой>.2`), **свой токен**, и **порты сервисов** (узнаем, когда опубликуют).

## secretscribble (WOTS-кука) — эксплойт прошлого года ГОТОВ и проверен

Из найденных сплойтов 2024 (`sploit_1/2/3.py`, сервис на порту 5005: `/sign`, `/cabinet/<id>/`,
«Закрытая информация»). **Баг:** сессионная кука `header.payload.signature` подписана схемой
**WOTS (Winternitz one-time signature)** с **одним глобальным ключом на все куки** и **без
контрольной суммы**. Каждая выданная кука раскрывает элементы хеш-цепочек; собрав ~30 кук и взяв
по каждому из 32 байт максимум, можно подписать любое сообщение, у которого все байты sha256 ≤
этих максимумов (хешируя цепочку вперёд). → Подделываешь куку с `id` жертвы → `/cabinet/<id>/`
отдаёт её флаг.

Адаптировано в [farm/sploits/secretscribble.py](farm/sploits/secretscribble.py) под интерфейс
фермы (`exploit(host, port, flag_id)`, `flag_id` = id кабинета жертвы; без `checklib`; коллекция
WOTS кешируется на бокс). **Проверено на точной копии схемы — крадёт флаг за ~1с.**
Оговорки: имя сервиса (`secretscribble`) — предположение; порт в 2024 был 5005 — в этом году
возьмётся из `config.forcad.py`; если `flag_id` окажется не числовым id, поправим пару строк.

**Патч (защита), не ломая SLA:**
- Проще всего — **серверные сессии**: кука = случайный непредсказуемый id, а привязка id→user
  хранится на сервере. Подделывать нечего. Чекеру (login→cabinet) всё равно работает.
- Либо подписывать куку нормальным **HMAC-SHA256** с серверным секретом вместо WOTS.
- Если оставлять WOTS — добавить **контрольную сумму Винтерница** и реально одноразовый ключ
  (одна подпись на ключ). Это сложнее и рискованнее для SLA; serverside-сессии надёжнее.

## Заметки по защите

- **zounds — клинер.** На сервисе есть «клинер», который удаляет файлы. Если он слишком
  агрессивный, он сносит флаги раньше, чем чекер успевает их забрать → падает SLA. Защита:
  **отключить/замедлить клинер** (дать ему больше времени на очистку), чтобы флаги жили дольше.
  Но не отключай полностью без присмотра — если файлы забьют диск, сервис упадёт (тоже SLA).
  Это не патч уязвимости, а настройка ради SLA.
- Общий цикл защиты и инструменты — в [defense/README.md](defense/README.md)
  (`verify.py` — валидатор патча, `trafmon.py` — разведка эксплойтов по трафику,
  `filter_proxy.py` — быстрый митигейт).

## Чек-лист на день открытия
1. Поднять WireGuard, проверить доступ к `10.10.10.10` и к соседним `10.60.*.2`.
2. В `farm/config.forcad.py`: вписать свой IP, токен; когда появятся сервисы — их порты.
3. `python farm/farm.py --config farm/config.forcad.py --once --dry-run` — убедиться, что
   attack_data парсится и цели видны.
4. На каждый сервис — эксплойт по шаблону (можно по чатам параллельно) → `farm/sploits/`.
5. `python farm/farm.py --config farm/config.forcad.py --loop` — атака пошла.
6. Параллельно: `tcpdump` + `defense/trafmon.py` — смотреть, чем бьют тебя, чинить/митигировать.
